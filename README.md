 LabLight - Analizador Óptico

Aplicación web interactiva diseñada para analizar experimentalmente y simular la *Ley del Inverso del Cuadrado* de la intensidad luminosa.

 Objetivo del Proyecto
Facilitar la recolección y el análisis de datos en el laboratorio, permitiendo a los estudiantes ingresar mediciones experimentales de forma manual o generar simulaciones teóricas para visualizar y contrastar los resultados en tiempo real.

Tecnologías Utilizadas
  HTML5 y CSS3: Estructura y diseño responsivo de la interfaz.
  JavaScript:Lógica de cálculo físico, manejo de datos y simulaciones.
  Tailwind CSS Estilizado moderno y modo oscuro adaptado para laboratorio.

 Instrucciones de Uso
1. Acceso en línea: Abre la aplicación desde cualquier navegador (computador o celular) ingresando a: [https://benjaminmesinas-sys.github.io/LabLight/](https://benjaminmesinas-sys.github.io/LabLight/)
2. Ingreso de datos: Selecciona el modo de medición manual para registrar la distancia (r) y la intensidad luminosa (I), o utiliza el modo de simulación.
3. Visualización: Observa la curva generada automáticamente en el gráfico para comprobar la relación inversamente proporcional al cuadrado de la distancia (I= 1/r^2).
